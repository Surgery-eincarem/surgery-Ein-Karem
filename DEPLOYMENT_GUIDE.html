7הגדרת DNS - חיבור הדומיין ל-GitHub

DNS = Domain Name System. זה השלב הקריטי שבו אנחנו "מצביעים" מהדומיין שלך לשרתי GitHub.

📚 הסבר טכני קצר: כשמישהו מקליד את הדומיין שלך בדפדפן, ה-DNS אומר לדפדפן "לך לכתובת ה-IP הזו" - שזה השרת של GitHub. נגדיר 4 IP-ים של GitHub.

שלב א': הגדרת DNS אצל ספק הדומיין

7.1
היכנס לפאנל הניהול

גש לאתר שממנו קנית את הדומיין, התחבר, ומצא את ניהול ה-DNS:

  • Cloudflare: Dashboard → בחר את הדומיין → DNS
  • Domain.co.il: ניהול דומיינים → רשומות DNS
  • Namecheap: Domain List → Manage → Advanced DNS
  • GoDaddy: My Products → DNS
7.2
הוסף 4 רשומות A

הוסף את הרשומות הבאות (זה ה-IP של שרתי GitHub Pages):

Type: A    Name: @    Value: 185.199.108.153
Type: A    Name: @    Value: 185.199.109.153
Type: A    Name: @    Value: 185.199.110.153
Type: A    Name: @    Value: 185.199.111.153
  • Type: A (כתובת)
  • Name / Host: @ (משמעות: הדומיין הראשי)
  • Value / Points to: כתובות IP מעל
  • TTL: Auto (או 3600)
7.3
הוסף רשומת CNAME ל-www

כדי שגם www.your-domain.com יעבוד:

Type: CNAME    Name: www    Value: your-username.github.io
⚠️ שים לב! ב-Value החליפו את your-username בשם המשתמש האמיתי שלכם ב-GitHub.

שלב ב': הגדרת הדומיין ב-GitHub Pages

7.4
חזור ל-GitHub Pages
  • היכנס לריפו שלך ב-GitHub
  • Settings → Pages
  • תחת "Custom domain" הזן את הדומיין שלך: surgres-pro.com (ללא https:// וללא www.)
  • לחץ "Save"
7.5
המתן לבדיקת DNS

GitHub יבדוק שה-DNS מוגדר נכון. זה יכול לקחת בין 10 דקות ל-24 שעות. במהלך הזמן הזה תראה:

DNS Check in progress...

כשהבדיקה תעבור בהצלחה, תראה:

✅ DNS check successful
⏰ למה זה לוקח זמן? כשמשנים DNS, השינוי צריך "להתפרסם" בכל שרתי ה-DNS בעולם. זה תהליך טבעי שלוקח זמן (DNS propagation). בדרך כלל 10-60 דקות, לפעמים עד 24 שעות.

8הפעלת HTTPS (חיבור מאובטח)

אחרי שה-DNS עובד, נפעיל HTTPS - חובה לאתר מקצועי, במיוחד במידע רפואי.

8.1
סמן "Enforce HTTPS"

בעמוד Settings → Pages:

  • מתחת לדומיין שהוגדר, יופיע צ'קבוקס "Enforce HTTPS"
  • סמן אותו ✅
🔒 HTTPS פעיל! GitHub Pages יוצר באופן אוטומטי תעודת SSL חינמית דרך Let's Encrypt. עכשיו הגלישה לאתר מוצפנת ומאובטחת לחלוטין.
⚠️ אם הצ'קבוקס מנוטרל: זה אומר שהתעודה עוד לא נוצרה. חכה 30-60 דקות נוספות ונסה שוב.

🔄 עדכון האפליקציה

כשתרצה לעדכן את האפליקציה (לדוגמה לאחר שינוי בקוד), התהליך פשוט:

A
דרך הדפדפן (קל)
  1. היכנס לריפו ב-GitHub
  2. לחץ על הקובץ שרוצים לעדכן (לדוגמה app.html)
  3. לחץ על אייקון העריכה (עיפרון ✏️)
  4. ערוך, גלול למטה, ולחץ "Commit changes"

B

  1. בריפו, לחץ "Add file" → "Upload files"
  2. גרור את הקובץ החדש (אותו שם)
  3. סמן "Replace" אם נשאל
  4. Commit changes
💡 טיפ למשתמשים: אחרי עדכון, המשתמשים שכבר התקינו את ה-PWA יקבלו את הגרסה החדשה אוטומטית בכניסה הבאה (תוך כמה שניות). אם משהו לא מתעדכן, צריך לרענן את הדף עם Ctrl+Shift+R.

  • וודא שכתובות ה-IP נכונות (אצל GitHub: 185.199.108.153 וכו')
  • חכה 1-24 שעות לפרסום DNS
  • השתמש בכלי בדיקה כמו whatsmydns.net

❌ ה-HTTPS לא נטען

  • נטרל ועניין מחדש את "Enforce HTTPS"
  • הסר את הדומיין ב-Settings → Pages וחזור והגדר אותו
  • חכה 1-2 שעות לתעודת SSL להיווצר

❌ שינויים לא מופיעים

  • נקה Cache: Ctrl+Shift+R (Windows) או Cmd+Shift+R (Mac)
  • בדוק ב-Actions שה-build הצליח
  • נסה במצב גלישה בסתר (Incognito)

❌ PWA לא נטען במובייל

  • וודא ש-HTTPS פעיל (חובה ל-PWA!)
  • בדוק שהקובץ manifest.json קיים
  • ב-iOS - חייב Safari (לא Chrome)
